# Установка — пошагово

Нужен Excel 2016 или новее на Windows. Ничего дополнительно не устанавливается. Займёт 5 минут.

Два способа. **Первый — надстройка:** один файл, своя вкладка на ленте, пункт в меню правой
кнопки. Подходит почти всем. **Второй — модули в `PERSONAL.XLSB`:** для тех, кто хочет держать
код в своей книге макросов или править его.

![Вкладка «Очистка ключей»](ribbon.png)

## Способ 1. Надстройка `excel-key-cleaner.xlam`

### Шаг 1. Скачать

Страница релизов: **https://github.com/MShkolenko/excel-key-cleaner/releases** → в последнем
релизе нажмите `excel-key-cleaner.xlam`. Файл скачается в «Загрузки».

### Шаг 2. Разблокировать

Windows помечает файлы из интернета, и Excel не запускает макросы из помеченного файла — вкладка
не появится или Excel покажет «Microsoft заблокировал запуск макросов». Один раз:

правая кнопка на `excel-key-cleaner.xlam` → **«Свойства»** → внизу галочка **«Разблокировать»**
→ ОК.

Если галочки нет — файл не помечен, идите дальше.

### Шаг 3. Положить в папку надстроек

Откройте Проводник, вставьте в адресную строку `%APPDATA%\Microsoft\AddIns` и нажмите Enter
(это папка `C:\Users\<ваше имя>\AppData\Roaming\Microsoft\AddIns` — стандартное место Excel для
надстроек пользователя; сама папка `AppData` в Проводнике скрыта, поэтому проще через адресную
строку). Скопируйте туда файл.

Можно положить и в любую другую папку — Excel запомнит путь. Не кладите только в «Загрузки»:
почистите их — надстройка пропадёт.

### Шаг 4. Включить

Excel → **`Файл → Параметры → Надстройки`** → внизу «Управление: **Надстройки Excel**» →
**«Перейти…»** → поставьте галочку **«Очистка ключей»** → ОК.

Если в списке её нет: «Обзор…» → выберите файл из шага 3 → ОК, галочка поставится сама.

Появится вкладка **«Очистка ключей»** сразу после «Главной». Надстройка включается при каждом
запуске Excel, пока галочка стоит.

### Шаг 5. Работать

1. Выделите ячейки, которые нужно почистить (столбец, диапазон, несколько областей через `Ctrl`).
   Макрос работает **только с выделением** — что не выделено, не тронет.
2. Вкладка **«Очистка ключей» → «Очистить ключи»**. Или правая кнопка по выделению → **«Очистить
   ключи»** (в самом верху меню).
3. В окошке с пятью флажками отметьте нужное (по умолчанию — 1, 2, 4; пункты 3 и 4 нельзя
   вместе; флажок 5 включайте только если в выделении одни коды) → **«Выполнить»** (или
   `Enter`). «Отмена», `Esc` и крестик ничего не меняют.
4. В конце появится отчёт: сколько ячеек просмотрено, сколько изменено, и **адреса всех ячеек,
   которые остались нетронутыми, с причиной** — после закрытия окна они выделены на листе.

Формулы, числа, даты, `#Н/Д` и пустые ячейки макрос не трогает — их можно смело оставлять в
выделении. Кнопка «Как это работает» открывает эту страницу проекта.

### Обновление и удаление

**Обновить:** закройте Excel, замените файл в папке надстроек новым (и снова «Разблокировать» —
шаг 2), откройте Excel. Галочку трогать не нужно.

**Выключить:** снимите галочку в том же окне («Перейти…» из шага 4). **Удалить совсем:** снимите
галочку и удалите файл.

**Раньше ставили макрос модулем в `PERSONAL.XLSB`?** Надстройка работает и рядом с ним: кнопки на
ленте вызывают свою копию. Но старая копия останется в `Alt+F8` и может отставать по версии —
удалите из `PERSONAL.XLSB` модули `Cleaning` и `CleaningForm` (`Alt+F11` → правая кнопка на
каждом → Remove → «Нет» на вопрос об экспорте → `Ctrl+S`).

### Надёжное расположение — чтобы не разблокировать при каждом обновлении

Excel запускает макросы без вопросов из **надёжных расположений** — папок, которым вы доверяете.
Папка надстроек пользователя по умолчанию в их число **не входит**. Если сделать её надёжной,
шаг 2 больше не нужен:

`Файл → Параметры → Центр управления безопасностью → Параметры центра управления безопасностью… →
Надёжные расположения → Добавить новое расположение… → Обзор…` → папка из шага 3 → ОК → ОК.

Цена: любой файл с макросами в этой папке будет запускаться без предупреждения. Для папки, куда
кладутся только надстройки, это обычная практика; если сомневаетесь — оставьте шаг 2.

## Способ 2. Модули в `PERSONAL.XLSB` или в книгу

### Шаг 0. Скачать файлы

В последнем релизе нажмите `excel-key-cleaner.zip` и распакуйте (правая кнопка → «Извлечь всё…»).
Внутри надстройка, эта инструкция, инструкция для ИИ-агента и три файла для этого способа:
`Cleaning.bas`, `CleaningForm.frm`, `CleaningForm.frx`. Эти три оставьте **в одной папке** — при
импорте формы Excel сам подхватит `.frx` из папки, где лежит `.frm`.

Если Windows или антивирус ругаются на файлы `.bas`/`.frm` — это обычные текстовые файлы, их можно
открыть Блокнотом и убедиться.

### Шаг 1. Разрешить макросы

Excel по умолчанию не запускает макросы. Один раз:

`Файл → Параметры → Центр управления безопасностью → Параметры центра управления
безопасностью… → Параметры макросов` → выберите **«Отключить макросы VBA с уведомлением»**
(это безопасный вариант: Excel будет спрашивать) → ОК.

Если файлы скачаны из интернета, а Excel при импорте говорит, что макросы заблокированы: правая
кнопка на файле → Свойства → внизу галочка **«Разблокировать»** → ОК.

### Шаг 2. Решить, куда ставить

**А. В личную книгу макросов `PERSONAL.XLSB`** — макрос будет доступен во всех книгах, всегда.

**Б. В конкретную книгу** — макрос живёт только в ней. Книгу тогда нужно сохранить как `.xlsm`
(«Книга Excel с поддержкой макросов»), иначе Excel при сохранении макрос выкинет и предупредит.

Если у вас нет `PERSONAL.XLSB` (в редакторе VBA слева нет строки `VBAProject (PERSONAL.XLSB)`),
создайте её за минуту: `Вид → Макросы → Запись макроса…` → в поле «Сохранить в» выберите
**«Личная книга макросов»** → ОК → сразу `Вид → Макросы → Остановить запись`. Всё, книга есть.

### Шаг 3. Импортировать два файла

1. Нажмите **`Alt+F11`** — откроется редактор VBA.
2. Слева в дереве «Project» щёлкните тот проект, куда ставите: `VBAProject (PERSONAL.XLSB)` или
   проект вашей книги. Это важно — импорт идёт в выделенный проект.
3. **`File → Import File…`** (в русском редакторе: `Файл → Импорт файла…`) → `Cleaning.bas`.
   В дереве под «Modules» появится `Cleaning`.
4. Ещё раз **`File → Import File…`** → `CleaningForm.frm`. Под «Forms» появится `CleaningForm`.
   Файл `.frx` выбирать не нужно — он подтянулся сам.
5. **`Ctrl+S`** прямо в редакторе VBA. Для варианта Б Excel спросит формат — выбирайте `.xlsm`.
6. Закройте редактор (`Alt+Q`).

Проверка: `Alt+F8` — в списке макросов есть `CleanKeys` (для `PERSONAL.XLSB` — с префиксом
`PERSONAL.XLSB!`).

### Шаг 4. Запустить

Выделите ячейки → **`Alt+F8`** → `CleanKeys` → «Выполнить» → дальше как в шаге 5 первого способа.

Чтобы не искать в списке: правая кнопка на панели быстрого доступа (полоска вверху окна) →
«Настройка панели быстрого доступа…» → «Макросы» → `CleanKeys` → «Добавить». Или горячая клавиша:
`Alt+F8` → `CleanKeys` → «Параметры…» → например `Ctrl+Shift+K`.

**Обновление:** удалить старые `Cleaning` и `CleaningForm` из проекта (правая кнопка → Remove →
«Нет» на вопрос об экспорте) и повторить шаг 3 с новыми файлами.

## Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| Вкладки «Очистка ключей» нет | Надстройка не включена (шаг 4) или заблокирована (шаг 2). Проверьте галочку в «Надстройки Excel»; если стоит — закройте Excel, «Разблокировать» файл, откройте снова |
| «Microsoft заблокировал запуск макросов, так как источник этого файла не является доверенным» | Шаг 2 («Разблокировать») или надёжное расположение |
| Кнопка на вкладке ничего не делает / «Макросы отключены» | Макросы выключены совсем (`Параметры макросов` → «Отключить все макросы без уведомления»). Выберите «с уведомлением» или сделайте папку надёжной |
| При импорте формы: «Не удаётся загрузить форму…» / форма пустая | `.frx` лежал не рядом с `.frm`. Удалите форму из проекта, положите три файла в одну папку, импортируйте `.frm` снова |
| `Alt+F8` не показывает `CleanKeys` | Способ 2: импортировали не в тот проект, либо книга сохранена как `.xlsx`. Способ 1: так и должно быть — макросы надстроек в `Alt+F8` не показываются, запуск с ленты |
| Отчёт: «Ячейка … заблокирована на защищённом листе» | Снимите защиту листа (`Рецензирование → Снять защиту листа`) и запустите снова. Ничего не изменилось — это отказ до первой записи |
| Отчёт: «КИРИЛЛИЦА ОСТАВЛЕНА в N яч.: …» | Это не ошибка: русские слова и коды, где кириллицы больше латиницы, макрос намеренно не меняет. Они выделены на листе — проверьте глазами. Если это точно коды, повторите на том же выделении с флажком 5 |
| Excel на Mac / Excel в браузере | Нужен Excel для Windows: на Mac форма (`MSForms`) не работает, в браузере макросов нет |
