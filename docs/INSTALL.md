# Установка руками — пошагово

Нужен Excel 2016 или новее на Windows. Ничего дополнительно не устанавливается. Займёт 5 минут.

## Шаг 0. Скачать файлы

1. Откройте страницу релизов: **https://github.com/MShkolenko/excel-key-cleaner/releases**
2. В последнем релизе нажмите `excel-key-cleaner.zip` — архив скачается в «Загрузки».
3. Распакуйте архив (правая кнопка → «Извлечь всё…»). Внутри четыре файла:
   `Cleaning.bas`, `CleaningForm.frm`, `CleaningForm.frx`, `INSTALL-FOR-CLAUDE.md`.
   Первые три оставьте **в одной папке** — при импорте формы Excel сам подхватит `.frx`
   из папки, где лежит `.frm`.

Если Windows или антивирус ругаются на файлы `.bas`/`.frm` — это обычные текстовые файлы,
их можно открыть Блокнотом и убедиться.

## Шаг 1. Разрешить макросы

Excel по умолчанию не запускает макросы. Один раз:

`Файл → Параметры → Центр управления безопасностью → Параметры центра управления
безопасностью… → Параметры макросов` → выберите **«Отключить макросы VBA с уведомлением»**
(это безопасный вариант: Excel будет спрашивать) → ОК.

Если файлы `.bas`/`.frm` скачаны из интернета, а Excel при импорте говорит, что макросы
заблокированы: правая кнопка на файле → Свойства → внизу галочка **«Разблокировать»** → ОК.

## Шаг 2. Решить, куда ставить

Два варианта:

**А. В личную книгу макросов `PERSONAL.XLSB`** — макрос будет доступен во всех книгах,
всегда. Рекомендуется, если пользоваться регулярно.

**Б. В конкретную книгу** — макрос живёт только в ней. Книгу тогда нужно сохранить как
`.xlsm` («Книга Excel с поддержкой макросов»), иначе Excel при сохранении макрос выкинет
и предупредит об этом.

Если у вас нет `PERSONAL.XLSB` (в редакторе VBA слева нет строки `VBAProject (PERSONAL.XLSB)`),
создайте её за минуту: `Вид → Макросы → Запись макроса…` → в поле «Сохранить в» выберите
**«Личная книга макросов»** → ОК → сразу `Вид → Макросы → Остановить запись`. Всё, книга есть.
(Если вкладки «Разработчик» нет — она и не нужна, «Макросы» есть на вкладке «Вид».)

## Шаг 3. Импортировать два файла

1. Нажмите **`Alt+F11`** — откроется редактор VBA (окно «Microsoft Visual Basic for Applications»).
2. Слева в дереве «Project» щёлкните тот проект, куда ставите: `VBAProject (PERSONAL.XLSB)`
   или проект вашей книги. Это важно — импорт идёт в выделенный проект.
3. Меню **`File → Import File…`** (в русском редакторе: `Файл → Импорт файла…`) → выберите
   `Cleaning.bas` → «Открыть». В дереве под «Modules» появится `Cleaning`.
4. Ещё раз **`File → Import File…`** → выберите `CleaningForm.frm` → «Открыть». В дереве под
   «Forms» появится `CleaningForm`. Файл `.frx` выбирать не нужно — он подтянулся сам.
5. **`Ctrl+S`** прямо в редакторе VBA (сохраняет ту книгу, куда импортировали).
   Для варианта Б Excel спросит формат — выбирайте `.xlsm`.
6. Закройте редактор (`Alt+Q` или крестик). Excel остаётся открытым.

Проверка: `Alt+F8` — в списке макросов есть `CleanKeys` (и его второе имя
`Замена_Кирилицы_С_Выбором`). Если ставили в `PERSONAL.XLSB`, имена будут с префиксом
`PERSONAL.XLSB!`.

## Шаг 4. Запустить

1. Выделите ячейки, которые нужно почистить (столбец, диапазон, несколько областей через `Ctrl`).
   Макрос работает **только с выделением** — что не выделено, не тронет.
2. **`Alt+F8`** → `CleanKeys` → «Выполнить».
3. В окошке с четырьмя флажками отметьте нужное (по умолчанию — 1, 2, 4; пункты 3 и 4 нельзя
   вместе) → **«Выполнить»** (или `Enter`). «Отмена», `Esc` и крестик ничего не меняют.
4. В конце появится отчёт: сколько ячеек просмотрено, сколько изменено, что пропущено и почему.

Формулы, числа, даты, `#Н/Д`, пустые и скрытые ячейки макрос не трогает — их можно смело
оставлять в выделении.

## Шаг 5 (по желанию). Кнопка, чтобы не искать в списке

**На панель быстрого доступа** (полоска вверху окна): правая кнопка на этой панели →
«Настройка панели быстрого доступа…» → в списке слева выберите «Макросы» → `CleanKeys` →
«Добавить» → «Изменить…» позволяет выбрать значок → ОК.

**Горячая клавиша:** `Alt+F8` → выделить `CleanKeys` → «Параметры…» → задать сочетание,
например `Ctrl+Shift+K`.

## Если что-то не так

| Симптом | Причина и что делать |
|---|---|
| При импорте формы: «Не удаётся загрузить форму…» / форма пустая | `.frx` лежал не рядом с `.frm`. Удалите форму из проекта (правая кнопка → Remove), положите все три файла в одну папку, импортируйте `.frm` снова |
| `Alt+F8` не показывает `CleanKeys` | Импортировали не в тот проект (см. шаг 3.2), либо книга сохранена как `.xlsx` и макрос выкинут — импортируйте снова и сохраните как `.xlsm` |
| «Макросы отключены» при запуске | Шаг 1; либо закройте и снова откройте книгу, нажав «Включить содержимое» в жёлтой полосе |
| Отчёт: «Ячейка … заблокирована на защищённом листе» | Снимите защиту листа (`Рецензирование → Снять защиту листа`) и запустите снова. Ничего не изменилось — это отказ до первой записи |
| Отчёт: «не тронуто ячеек с кириллицей: N» | Это не ошибка: так посчитаны русские слова и коды, где кириллицы больше латиницы — их макрос намеренно не меняет. Проверьте их глазами |
| Excel на Mac / Excel в браузере | Редактор VBA на Mac есть, но форма (`MSForms`) там не работает; в браузере макросов нет вообще. Нужен Excel для Windows |

## Обновление на новую версию

Удалить старые `Cleaning` и `CleaningForm` из проекта (правая кнопка на каждом → `Remove…` →
«Нет» на вопрос об экспорте) и повторить шаг 3 с новыми файлами. Не правьте код внутри
редактора вручную — следующая версия его перезапишет.
