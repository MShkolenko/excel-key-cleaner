# Установка excel-key-cleaner — инструкция для ИИ-агента (Claude, Codex, любой другой)

Это письмо адресовано ИИ-агенту, работающему на компьютере получателя. Человек прислал архив
`excel-key-cleaner.zip` (или ссылку на репозиторий) и попросил установить макрос. В архиве два
компонента VBA:

| Файл | Тип | Что внутри |
|---|---|---|
| `Cleaning.bas` | обычный модуль | `Sub CleanKeys()` (единственная точка входа; в 2.x был ещё псевдоним `Замена_Кирилицы_С_Выбором`, в 3.0 убран) — в выделенных ячейках заменяет кириллические омоглифы (А В Е К М Н О Р С Т Х а е о р с х) на латиницу, переносы строк на пробел, удаляет или нормализует пробелы, включая неразрывные, табуляцию и символы нулевой ширины |
| `CleaningForm.frm` + `CleaningForm.frx` | пользовательская форма (UserForm) | диалог с 4 флажками, который спрашивает, какие из четырёх действий выполнить, перед запуском макроса |

`Cleaning.bas` вызывает `CleaningForm.Show` — макрос **не заработает без формы**. Оба файла
нужно импортировать вместе. `.frx` — бинарный файл с описанием элементов формы, его никогда
не открывают и не импортируют отдельно: он должен просто лежать **в той же папке**, что и
`.frm` — Excel подхватывает его сам по имени.

Declare-вызовов (WinAPI) в коде нет — версия Office (x86/x64) роли не играет. Нужен Excel 2016 или
новее на Windows; Python, PowerShell и что-либо ещё для установки НЕ требуются — способ через
COM ниже лишь удобство для агента, ручной импорт через `Alt+F11` полностью равноценен.

Версия 3.0 (2026-09-22), после аудита и прогона на стенде (см. README и CHANGELOG в репозитории). Что важно знать о поведении:
- обрабатываются **все текстовые ячейки выделения**, включая скрытые строки и ячейки с разным оформлением
  символов (оформление сохраняется); формулы, числа, даты, ошибки (`#Н/Д`) и пустые - не текст, не трогаются,
  но считаются в отчёте; всё нетронутое называется по адресу и выделяется на листе;
- текст записывается как текст — `00123`, `12/03`, `1E5`, `=1+1` не превращаются в число, дату или формулу;
- кириллица меняется только в ячейках, похожих на код (есть латинская буква, и вся кириллица — омоглифы);
  русское слово вроде `ВЕТЕР` или `СМР-2` не трогается и считается как «пропущено с русским текстом»;
  `У/у` не заменяется намеренно;
- нормализация пробелов схлопывает повторы и обрезает края; неразрывный пробел, табуляция и редкие
  Unicode-пробелы считаются пробелом, символы нулевой ширины удаляются;
- план изменений считается до первой записи; заблокированная ячейка на защищённом листе — отказ до записи;
  ошибка при записи — откат уже записанных ячеек; закрытие формы крестиком или Esc = отмена.

## Куда ставить

Обычно — в личную книгу макросов `PERSONAL.XLSB`, чтобы макрос был доступен в любой книге:

```
%APPDATA%\Microsoft\Excel\XLSTART\PERSONAL.XLSB
```

Если файла нет — она создаётся автоматически при первой записи любого макроса через
`Разработчик → Запись макроса → Хранить в личной книге макросов`, либо этот же файл можно
создать программно (`Workbooks.Add` + `SaveAs` с `FileFormat=50` в папку `XLSTART`).

## Предпосылка: доступ к объектной модели VBA

Импорт компонентов через COM требует включённой опции **Trust access to the VBA project
object model** (по-русски — «Доверять доступ к объектной модели проектов VBA»):
`Файл → Параметры → Центр управления безопасностью → Параметры центра управления
безопасностью → Параметры макросов`.

Проверить программно:
```powershell
(Get-ItemProperty "HKCU:\Software\Microsoft\Office\16.0\Excel\Security").AccessVBOM
```
`1` — включено. Если `0` или ключа нет — **спроси человека включить галочку вручную**
(Claude не должен менять этот параметр реестра сам — это доверительная настройка
пользователя). Номер версии в пути (`16.0`) может отличаться — проверь фактическую версию
Office через `Get-ItemProperty "HKCU:\Software\Microsoft\Office\*\Excel\Options"` или просто
попробуй открыть `VBProject` и поймай исключение.

## Установка через COM (PowerShell) — если AccessVBOM включён

Закрой все открытые Excel перед записью (иначе сохранение не применится):
```powershell
Get-Process EXCEL -ErrorAction SilentlyContinue
```

Затем (пути подставь свои — куда распаковался архив и где лежит PERSONAL.XLSB):
```powershell
$personalPath = "$env:APPDATA\Microsoft\Excel\XLSTART\PERSONAL.XLSB"
$srcDir       = "<папка, куда распакован архив>"

$excel = New-Object -ComObject Excel.Application
$excel.Visible = $false
$excel.DisplayAlerts = $false
try {
    $wb = $excel.Workbooks.Open($personalPath)
    if ($wb.ReadOnly) { throw "PERSONAL.XLSB открыт в другом Excel - сначала закрыть" }

    # если компонент с таким именем уже есть - удалить перед повторным импортом
    foreach ($name in @('Cleaning','CleaningForm')) {
        foreach ($c in $wb.VBProject.VBComponents) {
            if ($c.Name -eq $name) { $wb.VBProject.VBComponents.Remove($c) }
        }
    }

    $wb.VBProject.VBComponents.Import((Join-Path $srcDir "Cleaning.bas"))
    $wb.VBProject.VBComponents.Import((Join-Path $srcDir "CleaningForm.frm"))
    $wb.Save()
    Write-Output "OK: Cleaning + CleaningForm импортированы в $personalPath"
}
finally {
    if ($wb) { $wb.Close($false) }
    $excel.Quit()
    [Runtime.InteropServices.Marshal]::ReleaseComObject($excel) | Out-Null
    [GC]::Collect(); [GC]::WaitForPendingFinalizers()
}
```

Проверка после импорта — прочитать компонент обратно и сверить число строк
(число строк см. в выводе `python build.py` в репозитории) или просто открыть `Alt+F11` и увидеть оба
компонента в дереве проекта `VBAProject (PERSONAL.XLSB)`.

## Если AccessVBOM выключен и человек не хочет его включать — ручной способ

1. `Alt+F11` в любой открытой книге Excel.
2. `File → Import File...` → выбрать `Cleaning.bas`.
3. `File → Import File...` → выбрать `CleaningForm.frm` (файл `.frx` должен лежать рядом в
   той же папке — подхватится сам).
4. Сохранить книгу (если ставите в `PERSONAL.XLSB` — сохранить именно её).

## Как запускать

Выделить ячейки → `Alt+F8` → `CleanKeys` → `Выполнить`. Появится форма с
четырьмя флажками (по умолчанию включены: замена кириллицы, переносы строк, нормализация пробелов;
выключено: полное удаление пробелов — пункты 3 и 4 взаимоисключающие). Enter = Выполнить, Esc = Отмена.

## Что НЕ делать

- Не переносить формулы: макрос сам пропускает ячейки с формулами (`cell.HasFormula = False`)
  — ничего чинить в коде под это не нужно.
