# excel-key-cleaner

Макрос Excel (VBA), который чистит коды и ключи в выделенных ячейках: кириллические буквы,
набранные вместо похожих латинских (`10UРH` → `10URH`), переносы строк, невидимые символы и
лишние пробелы. Сделан для таблиц, где ключи оборудования и работ копируются между системами
руками и потом не сходятся в `ВПР`/Power Query, потому что «одинаковые» строки различаются
одной русской буквой или неразрывным пробелом.

*An Excel VBA macro that cleans key codes in the selected cells: Cyrillic look-alikes typed
instead of Latin letters, line breaks, invisible characters and stray spaces. Text-only,
type-safe write-back, plan-then-write with rollback. README is in Russian; the code comments
are Russian too — the target audience works in Russian Excel.*

## Что нужно

**Только Excel 2016 или новее на Windows.** Ничего ставить не надо: ни Python, ни PowerShell, ни
надстроек. Два файла из [`dist/`](dist/) импортируются в редактор VBA — и всё (см. «Установка»).
В коде нет ничего новее Excel 2007 и нет `Declare`-вызовов, поэтому подходит и 32-битный Office.
Проверено на Excel 2024 x64, Windows 11 ru-RU.

Python и PowerShell в репозитории есть — но **только для разработки**: `build.py` пересобирает
`dist/` из `src/`, `tests/` гоняют макрос через Excel, `examples/make_demo.py` сгенерировал
демо-книгу. Всё, что они производят, уже лежит в репозитории готовым.

## Что делает

Выделяете ячейки → `Alt+F8` → `CleanKeys` → форма с четырьмя флажками:

| # | Действие | Что именно |
|---|---|---|
| 1 | Кириллица → латиница | `А В Е К М Н О Р С Т Х` и строчные `а е о р с х` → `A B E K M H O P C T X a e o p c x`. **Только в ячейках, похожих на код**: есть цифра, есть латинская буква, латинских букв не меньше кириллических, и вся кириллица в ячейке — из этого списка. `ВЕТЕР`, `СМР-2`, `МОСТ-A`, `Название работы` не трогаются и попадают в счётчик «не тронуто ячеек с кириллицей». Цена правила: короткий ключ вроде `СЕ.U1` (кириллицы больше, чем латиницы) тоже остаётся — он виден в том же счётчике. `У/у` намеренно не заменяется: русская «у» и латинская «Y» — разные буквы. |
| 2 | Переносы строк → пробел | `CRLF`, `CR`, `LF`, `U+2028`, `U+2029` |
| 3 | Удалить все пробелы | обычный, табуляция, неразрывный `U+00A0`, `U+1680`, `U+2000–200A`, `U+202F`, `U+205F`, `U+3000`; символы нулевой ширины `U+200B–200D`, `U+2060`, `U+FEFF` удаляются |
| 4 | Нормализация пробелов | те же символы приводятся к обычному пробелу, повторы схлопываются, края обрезаются; нулевой ширины — удаляются |

Действия 3 и 4 взаимоисключающие. По умолчанию включены 1, 2, 4.

## Чего он НЕ делает — и почему это главное

- **Работает строго по выделению.** Это локальный инструмент: что выделили — то и чистится, ни
  одной ячейки за пределами выделения. Целый столбец или `Ctrl+A` — тоже выделение, просто
  пустая часть отбрасывается. Отдельная проба в тестах сторожит ловушку `SpecialCells`,
  который на одиночной ячейке молча расползается на весь лист.
- **Обрабатывает только видимые текстовые константы.** Формулы, числа, даты, логические,
  ошибки (`#Н/Д`), пустые и скрытые (отфильтрованные) ячейки пропускаются и считаются в отчёте.
  Отбор через `SpecialCells(xlCellTypeConstants, xlTextValues)`, поэтому целый столбец или
  `Ctrl+A` обрабатываются за доли секунды, а не перебором миллиона ячеек.
- **Текст остаётся текстом.** Запись идёт через формат `@` с возвратом прежнего формата: `00123`
  не станет числом `123`, `12/03` — датой, `1E5` — `100000`, а `=1 + 1` — формулой.
  (Обычное `cell.Value = s` делает всё перечисленное, см. `docs/AUDIT.md`.)
- **Сначала план, потом запись.** Все новые значения вычисляются до первой записи; заблокированная
  ячейка на защищённом листе — отказ до того, как что-то изменилось; ошибка при записи — откат
  уже записанных ячеек к исходным значениям. `ScreenUpdating`, `EnableEvents`, `Calculation`
  возвращаются в исходное состояние на любом пути.
- **Крестик, Esc и «Отмена» ничего не меняют.** Макрос продолжает работу только если форма
  закрыта кнопкой «Выполнить» (`Tag = "OK"`). `Enter` = Выполнить.
- **Ячейки с разным оформлением символов внутри** (часть жирная, часть цветная) пропускаются —
  запись `Value` свела бы всё к одному оформлению.
- **Не транслитерирует.** `Ж` не станет `Zh`, `П` не станет `P`. Это исправление опечаток
  раскладки, а не перевод в латиницу; для транслита есть другие инструменты (см. ниже).
- **Не превращает кириллическую `О` в ноль и `З` в тройку** — без знания структуры ключа это
  угадывание.

Отчёт после запуска: сколько текстовых ячеек просмотрено, сколько изменено, сколько пропущено
скрытых / с оформлением / с русским текстом, сколько символов заменено, переносов и пробелов
убрано. «Изменений не найдено» — только если действительно ни одна ячейка не изменилась.

## Установка

Нужны два компонента: модуль `Cleaning.bas` и форма `CleaningForm.frm` + `CleaningForm.frx`
(бинарный файл с описанием элементов формы; лежит рядом с `.frm`, отдельно не импортируется).
Берите их из [`dist/`](dist/) (или `dist/excel-key-cleaner.zip`) — там они в кодировке cp1251,
которую ожидает редактор VBA. Файлы в `src/` — те же тексты в UTF-8, для чтения и ревью.

1. `Alt+F11` в Excel (в любой книге; для постоянного доступа — в `PERSONAL.XLSB`).
2. `File → Import File…` → `Cleaning.bas`.
3. `File → Import File…` → `CleaningForm.frm` (`.frx` подхватится сам из той же папки).
4. Сохранить книгу. Готово: `Alt+F8` → `CleanKeys`.

**Первый раз в редакторе VBA?** Пошаговая инструкция с меню русского Excel, включением макросов,
созданием `PERSONAL.XLSB`, кнопкой на панели и разбором типичных ошибок —
[`docs/INSTALL.md`](docs/INSTALL.md).

Второе имя той же процедуры — `Замена_Кирилицы_С_Выбором` (историческое, оставлено для кнопок,
которые на него уже назначены).

Программная установка (COM, PowerShell, требует включённого «Доверять доступ к объектной модели
проектов VBA») — `tools/Install-VbaComponents.ps1`. Инструкция для ИИ-агента, которому прислали
архив: [`docs/INSTALL-FOR-CLAUDE.md`](docs/INSTALL-FOR-CLAUDE.md).

Заявленный минимум — Excel 2016. Версии 2010–2013, скорее всего, тоже работают (в коде ничего
новее 2007), но на них не проверялось; Excel 2007 и старше — нет: там `SpecialCells` возвращал
неверный результат при более чем 8192 областях (на 2024 измерено 10 000 областей без ошибок).

## Тесты (для разработчиков)

Пользователю этот раздел не нужен. В `tests/` — стенд, который прогоняет **настоящий** VBA-код через COM в чистой книге без единого
изменения логики (в копии модуля подменяются две строки: имя модуля и вызов формы, `MsgBox`
перехватывается). 31 входная строка × 6 наборов флажков сверяются с эталонной моделью на Python,
плюс 18 проб на то, что не выражается строкой: `#Н/Д` в выделении, `Ctrl+A`, 32 767 символов,
защищённый лист, объединённые ячейки, разрывное выделение, скрытая строка, одиночная ячейка,
rich text, дата-время, текст `=1 + 1`, целый столбец с таймером.

```powershell
python tests\gen.py dist\Cleaning.bas out --v2
powershell -File tests\Run-CleaningAudit.ps1 -AuditDir out -FormDir dist
python tests\verify.py out            # ожидается: mirror agreement: 186 OK, 0 MISMATCH
type out\special.txt                  # исход каждой пробы
```

Нужны Windows, Excel, Python 3 и включённый доступ к объектной модели VBA. Стенд ничего не
сохраняет и не трогает файлы на диске.

## Как это появилось

Первая версия (посимвольная замена по всей строке, `cell.Value = s`, `For Each cell In
Selection`) прошла аудит: два независимых ревью (Claude и Codex) плюс этот же стенд. Найдено
12 подтверждённых дефектов, среди них молчаливые: текст перепарсивался в числа, даты и формулы;
`#Н/Д` в выделении ронял макрос посреди диапазона; крестик формы запускал обработку; русские
слова превращались в `BETEP`. Переписанную версию проверяли ещё дважды: замечания коллег
(`У→Y`, невидимые символы, глифы на форме) и второй круг Codex (обработчик ошибок до смены
состояния Excel, полнота проверки rich text, `МОСТ-A`, откат текущей ячейки). Выжимка с репро —
[`docs/AUDIT.md`](docs/AUDIT.md). Версии — [`CHANGELOG.md`](CHANGELOG.md).

## Похожие инструменты

- [УБРАТЬСЛУЧКИРИЛ](https://micro-solution.ru/projects/addin_vba-excel/del-rnd-kirill) —
  функция листа с той же идеей (замена случайной кириллицы), посимвольно по всей строке, без
  проверки «похоже ли на код»; заменяет также `У→Y` и `и→u`.
- [Транслитерация](https://excelvba.ru/code/TranslitAddin), [Транслит на planetaexcel](https://www.planetaexcel.ru/techniques/3/32/)
  — другая задача: перевод русского текста в латиницу целиком.
- Список визуально похожих символов — Unicode UTS #39 `confusables.txt`; здесь взято только то,
  что реально путается на русской раскладке.
- Штатные `СЖПРОБЕЛЫ`/`ПЕЧСИМВ` (`TRIM`/`CLEAN`) убирают только обычный пробел и коды 0–31 —
  неразрывный пробел и символы нулевой ширины они не видят, отсюда действия 3–4.
